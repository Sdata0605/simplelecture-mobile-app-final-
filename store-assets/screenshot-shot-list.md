## Tips for Capturing Screenshots
1. Use an emulator or device at 1080×1920 resolution (Pixel 6 or similar)
2. Enable "Do Not Disturb" mode to hide status bar notifications
3. Capture via ADB: `adb shell screencap -p /sdcard/screen.png && adb pull /sdcard/screen.png`
4. For overlay captions: use Figma, Canva, or Adobe Express to add branded text overlays in the brand green (#2BBD6E)
5. All screenshots should use the same device frame for consistency
